# 我的记账本儿 · 收支分析版

移动优先的个人账本查看网站。告诉 GPT 记账，由 GPT 写入 Notion；网页负责同步、查询、分析与备份，不提供新增、编辑或删除账单的入口。

## 功能

- 首页：月度收支、结余、趋势与最近账单。
- 明细 / 统计共用深度筛选：周、月、季度、年、自定义日期，收支类型、三级分类、商家、星期、金额上下限、关键词。
- 分类从原始账单动态生成，支持逐层钻取、完整分类树；空白分类和商家显示“未分类”。
- 环比、同比同时展示总额、差额、增长率、笔数和日均；当前未结束周期截取相同已过天数，短月封顶月末。周从周一开始，周同比按往前 52 周对齐星期。自定义日期对比前一个等长时段、上年同日起等长时段（闰日落在上年二月末）。
- 每日 / 累计双曲线、精确金额表、分类占比与排行、商家排行、星期分布、金额分布和每日金额日历；图表可钻取到账单。
- 筛选结果 CSV 导出，防止单元格公式执行；账单只读详情；保留本机备份导入导出。
- 自定义分析范围最多 366 天；长账单列表按 50 笔逐步加载。

## 数据解释

默认首次打开可查看明确标注的演示数据；连接 Notion 后展示真实账单。无交易记录不代表该期已完整记账。金额单位元，按分汇总。平均每笔 / 日均流水按筛选下的收支金额合计计算；结余是收入减支出。基期为零不计算增长率。

## 开发与验证

无需构建，GitHub Pages 从默认分支根目录发布。`index.html`、`app.js`、`analytics.js`、`styles.css`、`sw.js` 与资源文件保持同目录。

运行 `node analytics.test.cjs` 验证跨年、季度、周对齐、闰年、金额汇总及筛选。预览可运行 `python3 -m http.server 8088 --bind 127.0.0.1`。

## 现有限制

Worker 最多读取 5000 笔；超出会报错，需要进一步支持分页或归档。前端只展示收到的账单，不推断缺失的历史周期。未添加预算、标签、账户等 Notion 当前接口未提供的字段。
